# 页面布局库

新产品或新页面在定布局时读。下面每种布局都来自一个国内口碑项目的真实界面（2026-10-24 在官网和产品截图里观察）。按项目的**核心动作**选一种，再按需要改，不要所有项目都用同一个骨架。组件细节见 [组件配方](../assets/patterns.html)，颜色和字体见 [视觉规范](visual-style.md)。

## 默认步骤

1. 用一句话写出用户打开页面后最常做的一件事，例如“看今天要做什么”“写下一条想法”“和 AI 对话”。
2. 在下表里找做同一件事的参考项目，用它的骨架。
3. 按“防空洞”规则检查：每一栏都有足够内容，没有大块空白。
4. 写清楚手机上怎么变：哪一栏留下，哪一栏变成抽屉、底部标签或单独页面。
5. 在交付报告里写一句选了哪种布局、参考了谁、为什么。

## A. 分组列表（滴答清单）

```text
┌──┬──────────┬───────────────────────┬──────────────┐
│图│ 今天  11 │ 收集箱            ⇅ ⋯ │ 选中项的详情 │
│标│ 最近7天   │ [＋ 添加任务        ]  │              │
│栏│ 收集箱 ●  │ ▾ 今天 4               │              │
│  │ ──────── │  □ 晨跑          07:00 │              │
│  │ 清单      │  □ 去超市        09:00 │              │
│  │ 🚀 九月计划│ ▾ 明天 3               │              │
│  │ 💼 认真工作│  □ 拍摄视频      08:00 │              │
└──┴──────────┴───────────────────────┴──────────────┘
 56px  200–240px     主列表 480–640px      详情 320–400px
```

- 列表是主角：一行一件事，按时间或状态分组，组标题带数量。
- 摘要很短：统计放在列表上方一行，或放在侧栏的入口数字里，不单独占一张大卡片。
- 详情在右栏打开，不跳页；没有选中时右栏可以收起，主列表变宽。
- 手机：只留主列表；侧栏变成顶部的标签切换或抽屉；详情变成新页面或底部面板；添加按钮固定在底部。

## B. 侧栏 + 卡片流（flomo）

```text
┌──────────────┬──────────────────────────────┐
│ 2659 723 449 │ [ 写点什么…              ▶ ] │
│ 笔记 标签 天  │                              │
│ ▦▦▦▦▦▦▦▦▦▦ │ ┌──────────────────────────┐ │
│ ▦▦▦▦▦ 热力图 │ │ 10-24 09:12          ⋯   │ │
│              │ │ 一条想法……  #标签         │ │
│ ● 全部笔记    │ └──────────────────────────┘ │
│   每日回顾    │ ┌──────────────────────────┐ │
│ 标签          │ │ ……                       │ │
│ 📚 读书       │ └──────────────────────────┘ │
└──────────────┴──────────────────────────────┘
   240–280px          内容 600–720px，居中
```

- 侧栏上半部分放“成就感”：几个统计数字加一张热力图，让人想继续记。
- 内容区是一列卡片（每条记录一张卡，这里卡片是对的，因为每条是独立的一段文字）。
- 输入框在最上面，永远可见。
- 手机：侧栏变成左上角的抽屉；输入框固定在顶部或底部。

## C. 文档树 + 编辑器（思源笔记）

```text
┌────────────┬─────────────────────────────┬──────────┐
│ 文档        │ 面包屑 > 当前文档      🔒 ⋯ │ 大纲      │
│ ▾ 📘 指南   │ [题图]                      │ H2 开始   │
│   🎉 开始   │ 标题                        │ H2 概念   │
│   🧱 内容   │ 正文，最大宽度 720px          │          │
└────────────┴─────────────────────────────┴──────────┘
   220–280px            编辑区自适应                180–220px
```

- 每个文档和文件夹前有 emoji，树形结构一眼能分清。
- 编辑区正文宽度不超过 720px，两边留白；大纲栏在宽屏才显示。
- 手机：只留编辑区，文档树和大纲都变成抽屉。

## D. 会话列表 + 对话（LobeChat、Cherry Studio）

```text
┌──┬──────────────┬─────────────────────────────────┐
│头│ 🔍 搜索       │ 助手名 · 模型          ⚙ ⋯      │
│像│ 🧑‍💻 代码助手  │                                 │
│栏│ ✍️ 写作助手   │   AI 回答（无气泡，全宽排版）    │
│  │ 📊 数据分析   │                  ┌ 用户消息气泡 ┐ │
│  │ ＋ 新对话     │ ┌─────────────────────────────┐ │
│  │              │ │ 输入框，大圆角，工具在下方     │ │
└──┴──────────────┴─┴─────────────────────────────┴─┘
 56px   240–280px         对话内容最大 800px，居中
```

- 每个助手或会话有自己的头像或 emoji。
- AI 回答不用气泡，按文章排版（Markdown、代码块、表格）；用户消息用浅色气泡靠右。
- 输入框固定在底部，圆角 16–20px，模型选择、附件等工具放在输入框里面的下方。
- 流式输出时可以随时停止；代码块右上角有复制按钮。
- 手机：会话列表是第一页，点进去是对话页。

## E. 三栏阅读器（Folo）

```text
┌──────────────┬──────────────────┬────────────────────────┐
│ 📰 订阅源     │ 时间线            │ 文章标题                │
│   少数派  12  │ 标题             │ 来源 · 时间              │
│   阮一峰   3  │ 摘要两行……  配图  │ 正文 680px              │
│ 📺 视频       │ 标题             │                        │
└──────────────┴──────────────────┴────────────────────────┘
   220–260px        320–400px              剩余宽度
```

- 左边是来源，按类型分组并带图标和未读数；中间是条目；右边是阅读。
- 不同内容类型（文章、视频、图片）在中间栏用不同的条目样式。
- 手机：三栏变成三页逐级进入。

## F. 单栏 + 浮动导航（Innei）

```text
            ┌───────────────────────────┐
            │ 头像  名字                 │
            │ 一句介绍                   │
            │ 最近文章 / 动态 / 项目      │
            │ ……                        │
            └───────────────────────────┘
               ╭─────────────────────╮
               │ 首页 文章 手记 关于 ≡ │   ← 底部浮动胶囊导航
               ╰─────────────────────╯
```

- 内容单栏居中，最大 680–760px；纸白底、衬线或优雅的中文字体，文字是主角。
- 导航是浮在底部的圆角胶囊，滚动时可以收起。
- 作品集：每个作品一张真实截图 + 一句话，不超过 6 个。

## G. 顶栏 + 卡片网格（Dify）

```text
┌──────────────────────────────────────────────────┐
│ Logo  探索  工作室  知识库  工具        👤        │
├──────────────────────────────────────────────────┤
│ [全部][聊天][工作流]            🔍 搜索  ＋ 创建  │
│ ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐     │
│ │🤖 名称  │ │📚 名称  │ │…       │ │…       │     │
│ │两行描述 │ │        │ │        │ │        │     │
│ │标签 · 时间│ │        │ │        │ │        │     │
│ └────────┘ └────────┘ └────────┘ └────────┘     │
└──────────────────────────────────────────────────┘
```

- 管理“多个项目”时用卡片网格，每张卡有图标、名称、两行描述、标签和更新时间；第一张可以是“＋ 创建”。
- 进入单个项目后换成侧栏导航 + 内容区。
- 企业级后台也从这里起步：顶栏切换模块，模块内用侧栏 + 表格；表格行高 48px 左右，筛选放在表格上方一行。

## H. 落地页（Cherry Studio、Dify、Bob）

```text
            一句大标题，点亮一两个词
            一句说明（灰色，18px）
            [ 黑色主按钮 ]   次要链接
     ┌──────────────────────────────────┐
     │      真实的产品截图或可交互演示     │
     └──────────────────────────────────┘
       功能 1     功能 2     功能 3   （每个配真实截图）
```

- 首屏居中，标题 40–56px，只点亮一两个词（强调色、渐变或下划线）。
- 截图紧跟在按钮下面，是首屏的一部分。
- 个性只放一处：Bob 的吉祥物、Cherry 的波浪下划线。

## 防空洞规则

- **两栏要等高**：并排的两栏内容高度相差超过一半时，改成一栏（摘要放上面），或者把短的一栏设成 `position: sticky` 并减小宽度。
- **稀疏数据不画柱状图**：30 天里有数据的日子不到三分之一时，不画 30 根柱子，改成“接下来几笔”的短列表、日历条或时间线。
- **卡片里内容要撑得起卡片**：一张卡片里只有一两行字时，不用大内边距和大卡片，改成一行摘要。
- **控制最大宽度**：阅读和列表区 640–760px，整页 1040–1200px；宽屏多出来的空间留给侧栏或详情栏，而不是把一栏拉得很宽。
- **截图检查**：桌面截图里，有没有超过一屏四分之一的大块空白？有的话按上面四条调整。
