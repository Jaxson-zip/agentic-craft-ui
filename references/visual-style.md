# 视觉规范：浅色、按项目选色和布局、自带中文字体

项目没有设计系统时的默认审美，适用于个人项目：效率工具和笔记、AI 应用、个人网站和作品集，也能延伸到企业级后台。

它来自对国内 9 个口碑很好的独立和开源项目的实测（2026-10-24，在浏览器里读取它们实际使用的字体和颜色）：LobeChat（Lobe UI）、Cherry Studio、Dify、Folo、Innei（Shiro 博客主题）、思源笔记、flomo、滴答清单、Bob。

先打开 [示例页面](../assets/demo.html) 亲手用一下（在 `assets/` 下运行 `python -m http.server`，再打开 `/demo.html`）：记一条带 `#标签` 的想法、点标签筛选、按 Ctrl/⌘ + K 搜索、删除后撤销。数值都在 [themes.css](../assets/themes.css) 里。

## 先看组件配方

[组件配方](../assets/patterns.html) 把 flomo 和滴答清单的界面拆成了六个常用组件，每个都并排放了“照做”和“不要这样”。写界面前先打开它，列表、图标、数字、图表、输入框、侧栏直接照左边的写法做。最常见的错误都在右边：

- **每一行做成一张带边框的卡片**，再塞徽章、进度条和按钮。列表应该是扁平的：按“今天 / 本周”分组，一行只有图标、标题加一行说明、右边一个数字或时间；编辑删除放进悬停菜单或详情页。
- **没有图标**。每个实体都要有一个：品牌用品牌色浅底方块或真实 logo（`simple-icons`、`@lobehub/icons`），用户自建的内容用 emoji。
- **数字用 800 粗体**。首屏大数字用 600，统计数字用 500，下面配一行小灰字或一句人话。
- **图表用深灰色**。只用强调色的深浅：普通值用浅色，“今天”或“最高”用实色。
- **提示条用大块彩色底**。用中性浅灰底，强调色只给里面的链接。

## 这些项目的共同点（照着做）

1. **浅色为主**：9 个首页没有一个默认深色。深色作为可选主题提供。
2. **主按钮用近黑色，全站只有一个强调色**：Lobe UI 和 Cherry Studio 的主按钮是黑色；flomo 只有绿，Folo 只有橙，Dify 只有蓝。强调色只用于选中、关键词、链接和焦点。
3. **字体随项目打包**：Lobe UI 首选 HarmonyOS Sans，Innei 加载 MiSans，Folo、Cherry、滴答自带 Geist 或 Inter。不能指望用户电脑上的微软雅黑，否则中文和数字会落到两套字体上，看起来别扭。
4. **标题只点亮一两个词**：Lobe 的渐变词、flomo 的绿色第二行、Dify 的“生产级”、Cherry 的彩色波浪下划线。其余文字保持黑白。
5. **首屏放真实界面**：Cherry、思源直接放产品截图，作品集也应如此，不靠装饰图撑场面。
6. **个性只放一处**：Bob 的吉祥物、滴答的插画图标、思源和 Lobe 的 emoji。只放一处，不做满屏特效。

## 默认步骤

1. 选字体：中文界面装 MiSans（`npm install misans`）或 HarmonyOS Sans；需要英文品牌感时，英文另加 Inter 或 Geist。
2. 按下面“颜色：按项目选”的四步定强调色：先按领域定色相，再用 `scripts/accent.py --avoid` 做避让，生成四个配套值替换 themes.css 里的示例值。
3. 按 [页面布局库](layouts.md) 选布局，再选一个招牌交互。
4. 用成熟组件库时，用它的主题机制注入 tokens（见 [平台与组件库](platforms.md)）。
5. 桌面和 375px 手机各截一张图，亲手试一遍招牌交互，对照“自查”。

## 字体与排版

| 项目 | 默认做法 |
| --- | --- |
| 字体栈 | `"MiSans", -apple-system, "PingFang SC", "HarmonyOS Sans SC", "Microsoft YaHei", sans-serif`（`--font-sans`） |
| 加载方式 | 用 npm 安装后引入对应字重的 CSS。字体按 `unicode-range` 切成分片，浏览器只下载页面用到的字。不要用 Google Fonts，大陆打不开 |
| 字重 | 正文 400，强调 500，标题 600。不要整段加粗 |
| 字号 | 正文 15px，行高 1.7；辅助文字 12–13px；页面标题 26px；落地页大标题 40px 起 |
| 字距 | 中文保持 0 或 +0.01em。负字距只给纯英文大标题（Folo、Cherry 都是 -1 到 -2px） |
| 文案 | 口语、短句；中英文之间加空格；见 [中国用户](china.md) |

## 颜色：按项目选

强调色每个项目单独定，按下面四步走，顺序不能反：**先按领域定色相，再做避让，最后生成配套色并写进报告**。

### 第一步：已有品牌色就直接用

用户或项目已有 logo、品牌色、设计稿时，直接用它，跳到第三步。

### 第二步：没有品牌色时，按项目领域定色相

找到项目所属的领域，用第一选择。只有第三步发现冲突时才换第二选择。不要因为“想安静一点”就跳到别的领域的颜色。

| 项目领域 | 第一选择 | 第二选择 | 参考 |
| --- | --- | --- | --- |
| 任务、日程、提醒、订阅和账单这类“到期管理” | 蓝 `#4772FA` | 靛蓝 `#5B5BD6` | 滴答清单 |
| 笔记、习惯、读书、健康、生活记录 | 薄荷绿 `#30CF79` | 青 `#14B8A6` | flomo |
| 阅读、信息流、社区、内容消费 | 橙 `#FF5C00` | 琥珀 `#E8A100` | Folo |
| 写作、创作、AI 内容生成 | 紫 `#7B61FF` | 品红 `#D946EF` | LobeChat 的紫粉渐变 |
| AI 对话、AI 助手 | 近黑无彩色，标题一处紫粉渐变 | 紫 `#7B61FF` | LobeChat、Cherry Studio |
| 开发者工具、企业后台、数据平台 | 电光蓝 `#0033FF` | 近黑无彩色 | Dify |
| 翻译、截图这类即用即走的小工具 | 灰蓝 `#5672CD` | 蓝 `#4772FA` | Bob |
| 个人博客、作品集 | 作者喜欢的颜色；没有就近黑无彩色 | 暖橙 `#E8590C` | Innei |
| 记账、理财 | 蓝 `#4772FA` | 紫 `#7B61FF` | 不用红绿做强调，避免和涨跌语义冲突 |

一个项目跨多个领域时，按用户**最常做的那件事**归类，例如“AI 写作助手”归写作，“订阅看板”归到期管理。

### 第三步：只和“大面积、反复出现”的颜色避让

把页面上反复出现、面积大的颜色列出来，例如平台标签（小红书红、公众号绿）、产品自己的大图标。运行：

```text
python scripts/accent.py "#7B61FF" --avoid "#FF2442,#07C160"
```

- 色相差 **≥ 30°**：可以共存，保留第一选择。
- 色相差 **< 30°**：冲突，换成同一行的第二选择，再跑一遍。
- 列表里一个个小的品牌 logo（Netflix 红、ChatGPT 绿）**不算冲突**：它们已经用 14% 浅底方块收住了，不要为了躲它们把强调色改成灰蓝。

### 第四步：生成配套色，并在报告里写清楚

上面的命令同时输出 `--accent`、`--accent-text`、`--accent-soft`、`--focus-ring` 的浅色和深色值，并检查对比度，贴进 themes.css 即可。交付报告的视觉一行必须写：

- **选了什么**：颜色值、所属领域、是第一选择还是第二选择。
- **备选**：至少一个考虑过的其他颜色。
- **放弃理由**：为什么没选备选；如果换到了第二选择，写出和哪个颜色冲突、色相差多少度。

用户不喜欢就换，换色只改这四个值。

其余颜色所有项目通用：

- **中性色**：带一点暖意的石灰色（`#FAFAF9` 页面、`#FFFFFF` 卡片、`#1C1917` 文字、`#67615C` 辅助）。
- **主按钮**：`--brand-primary` 默认近黑色，深色主题里反转成近白色。品牌色很重要的产品（比如滴答）也可以让主按钮用强调色。
- **强调色只用在小地方**：选中项、时间、关键词、链接、图表。全站只有这一个彩色。
- **标签和图表**：需要多种颜色时才用 `--data-1` 到 `--data-6`，它们亮度相同、只换色相。

## 布局：按项目选

先看 [页面布局库](layouts.md)：按核心动作选一种参考布局（滴答的分组列表、flomo 的侧栏加卡片流、思源的文档树、LobeChat 的对话、Folo 的三栏阅读、Innei 的单栏博客、Dify 的卡片网格、落地页），并按里面的“防空洞”规则检查。

每种项目类型可以配的招牌交互：

| 类型 | 招牌交互 |
| --- | --- |
| 效率工具、笔记 | 快速记录：回车保存，新条目从输入框“落”进列表；Ctrl/⌘ + K 命令面板 |
| AI 应用 | 流式输出时的光标和逐段淡入；随时可停；代码块一键复制 |
| 个人网站、作品集 | 悬停时截图轻微放大、标题下划线展开；页面切换用共享元素过渡 |
| 落地页 | 截图随滚动轻微视差，或点标签切换不同功能截图 |
| 企业级后台 | 表格行内编辑、可撤销的批量操作 |

## 动效

| 场景 | 做法 |
| --- | --- |
| 按下 | 缩到 0.97（图标按钮 0.92），100ms |
| 悬停 | 只变背景、阴影或颜色，不位移 |
| 列表增删和重排 | FLIP：记录旧位置 → 更新 → 从旧位置平滑移到新位置，约 320ms，`--ease-out` |
| 新内容进入 | 从触发它的位置出现（示例：从输入框落进列表），带一点回弹 |
| 面板、提示 | 淡入并轻微放大或上移，`--ease-spring`，不超过 350ms |

原则（来自 [Vercel Web Interface Guidelines](https://github.com/vercel-labs/web-interface-guidelines) 和 [Emil Kowalski](https://emilkowal.ski/ui/great-animations)）：

- 大多数动画不超过 300ms；高频操作（键盘、菜单）尽量不加。
- 只动 `transform` 和 `opacity`；不写 `transition: all`。
- 动画能被打断；动画没结束就撤销，结果也要正确（示例里的删除与撤销）。
- 删除等破坏性操作给“撤销”，而不是弹确认框。
- `prefers-reduced-motion` 下关掉动画，结果照常显示。

## 自查

- 中文和数字是不是同一套字体？在 Windows 上也看过吗？
- 除了强调色，页面上还有没有别的彩色？主按钮是不是近黑色？
- 标题是不是只点亮了一两个词？
- 有没有一个和产品核心动作相关、亲手试过的招牌交互？
- 手机宽度下按钮有没有压住文字？
- 再按 [防模板化自查](art-direction-motion.md#防模板化自查) 看一遍。好不好看，最终由用户判断。
