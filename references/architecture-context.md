# 架构与上下文

用于跨模块功能、已有应用改造、接口或数据模型变化；小修复仅执行与其相关的检索和快照核对。

多租户、多个业务领域或独立运行的 API/worker 涉及的系统设计，另读 [SaaS 架构](saas-architecture.md)。符号索引不能替代这些系统边界的分析。

## 定位与技术栈

先检索文件和符号，读取受影响的入口、实现、消费者、测试与配置。已有地图能帮助定位，但源码与实际运行结果优先。沿重导出、依赖、权限和持久化路径扩大阅读范围；不限制文件数量，也不无目的全盘加载。

检查清单与锁文件后选择包管理器和已有命令。CLI、Python、Go 等项目遵循自己的结构，不套 `src/contracts`、TypeScript 或 npm。缺少关键信息时读取相关配置，不靠风格预设推断框架。

## 轻量符号地图

Python 3.9+ 可运行标准库脚本。它读取目标范围内的源码来建立索引，但仅把摘要交给模型；不等于完全不读磁盘上的源码。

以下例子中 skill 安装在项目的 `.agents/skills/agentic-craft-ui`；安装位置不同时替换脚本路径。从应用项目根目录运行：

```text
python .agents/skills/agentic-craft-ui/scripts/repo_map.py . --output docs/REPO_MAP.md --snapshot docs/repo-map.snapshot.json
python .agents/skills/agentic-craft-ui/scripts/repo_map.py . --check docs/repo-map.snapshot.json
```

支持 JS/TS 常见扩展与 `.vue` 的 script 块；识别常见声明、具名导出、别名、重导出和默认导出，记录行号。无导出的文件也列入清单。默认显示全部已识别符号；`--max-symbols N` 的省略量会显示。

局限：不是完整解析器，不生成函数签名、依赖边或架构图。复杂模板、正则字面量、JSX 文本、解构、多变量声明、CommonJS 和非标准语法可能漏报或误报；Vue 的模板依赖和 setup 局部绑定不会成为 export。用源码与项目工具补充判断。

## 快照更新

JSON 保存索引范围、生成时间、版本和源码/配置内容指纹。相同范围下，源码内容、路径、文件增删、已覆盖配置或锁文件变化均使快照失效，包含符号名不变的函数体修改。

- 检查退出码 `0`：索引范围内内容未变，仍需核对任务涉及的源码。
- `1`：过期；重新生成索引，审查并更新受影响的架构说明。
- `2`：目录、快照、读取或其他错误；修复错误或转用源码检索，不能认定新鲜。

检测会重新读取范围内文件计算哈希；减少的是重复加载到模型的上下文，不承诺固定 Token 节省或耗时。

只覆盖 JS/TS/Vue 与脚本定义的配置/锁文件。SQL、其他语言、环境配置与外部系统变化需单独检查；未包含在指纹中的架构不能据此称为最新。脚本跳过依赖、构建目录与符号链接，不读取 `.gitignore`，大仓库使用最小相关子项目根目录。若缩小到 `src`，项目根配置不在覆盖范围。

快照绝不是不可修改的真相。每次改接口、边界、路由、权限或数据模型后，同步维护对应文档；修改文档不等于已经核对源码。

## 架构文档

新产品或显著跨模块变化时，在项目现有文档中记录：范围、依据文件/行号、关键决策、接口、身份边界、已知假设和验证状态。没有既有位置时可用 `docs/ARCHITECTURE.md`。不要为小修复创建整套排期和架构文件。

按问题选择 Mermaid：系统边界用分层图；关键调用与失败流用时序图；有持久化模型时才用 ER 图。节点和关系必须来自已核对的实现或明确标为拟议设计；导出列表不足以证明调用链、事务或表关系。

契约至少覆盖输入、输出、错误语义、身份/权限和状态变化。优先项目现有 schema 或接口规范；没有时选适合项目的机制。区分编译时类型与运行时校验。

老项目使用渐进替换：先记录现状和回归边界，再建立局部新契约，替换受影响路径，最后清理已证明不再使用的旧代码。不要用导出地图证明代码无引用，也不按功能数量强制重构。
