# UI 指南

做界面时读。下面都是**默认值**：项目已有设计系统、品牌或用户明确要求时，以它们为准。

## 1. 先选底座

| 平台 | 推荐 | 说明 |
| --- | --- | --- |
| 网页（个人项目、AI 应用） | React + Tailwind + shadcn/ui；AI 对话可用 Lobe UI | shadcn 组件是复制进项目的源码，改主题最自由 |
| 网页（企业后台、数据密集） | Ant Design、Arco Design、Semi Design、TDesign | 表格、表单、权限类组件最全 |
| 网页（Vue） | Arco Design Vue、TDesign、Element Plus | 已用 Vue 就继续用 Vue |
| 微信小程序 | 原生 + TDesign 小程序 / Vant Weapp；多端用 Taro 或 uni-app | 没有 DOM，主包有大小限制，审核前真机预览 |
| 手机 App | uni-app、Taro、React Native、Flutter | 已有 Web 栈优先 uni-app 或 React Native |
| 小工具、单页 | 原生 HTML/CSS/JS | 不必为一页引入框架 |

**一定要换掉默认主题**，至少改主色、圆角、字体、阴影：

```css
/* shadcn/ui：globals.css */
:root { --primary: 240 6% 10%; --radius: 0.75rem; --ring: 228 95% 63%; }
```

```tsx
// Ant Design
<ConfigProvider theme={{ token: { colorPrimary: '#4772FA', borderRadius: 10, fontFamily: 'MiSans, "PingFang SC", sans-serif' } }}>
```

Arco、TDesign、Vant 都用 CSS 变量覆盖，写在全局样式里，不要到处写覆盖样式。

## 2. 默认审美，以及什么时候偏离

没有设计系统时，默认参考 flomo、滴答清单、LobeChat、Cherry Studio 这类国内独立产品：

- 浅色为主；中性色带一点暖意（页面 `#FAFAF9`、卡片 `#FFFFFF`、文字 `#1C1917`、辅助 `#67615C`）。
- 主按钮近黑色，全站只有一个强调色，只用在选中、时间、关键词、链接、图表上。
- 个性只放一处：一个吉祥物、一套插画图标或 emoji，不做满屏特效。

下面这些项目**不适用**默认审美，按右栏做：

| 项目 | 做法 |
| --- | --- |
| 开发者工具、终端、代码类 | 默认深色，等宽字体做主角，强调色用亮绿或亮蓝，信息密度高 |
| 电商、促销、活动页 | 大面积品牌色和高饱和撞色，大图和价格是主角，按钮醒目 |
| 数据大屏、监控 | 深色底，大数字和图表铺满，颜色按数据含义（正常 / 告警 / 故障） |
| 政企、审批、传统行业后台 | 直接用 Ant Design 或 TDesign 的规范，蓝色主色，表格和表单为主，少做装饰 |
| 品牌官网、作品集、游戏 | 按品牌或作者个性另定风格，可以大胆 |

## 3. 颜色

强调色每个项目单独定：

1. 有品牌色就用品牌色。
2. 没有就按领域选：

| 领域 | 强调色 |
| --- | --- |
| 任务、日程、订阅、账单等“到期管理” | 蓝 `#4772FA`（滴答） |
| 笔记、习惯、读书、生活记录 | 绿 `#30CF79`（flomo） |
| 阅读、信息流、社区 | 橙 `#FF5C00`（Folo） |
| 写作、创作、AI 内容生成 | 紫 `#7B61FF` |
| AI 对话助手 | 近黑，标题一处紫粉渐变（LobeChat） |
| 开发者工具、企业后台 | 电光蓝 `#0033FF`（Dify）或近黑 |
| 小工具、翻译 | 灰蓝 `#5672CD`（Bob） |

3. 只和页面上**大面积、反复出现**的颜色（比如小红书红、公众号绿的平台标签）避开：色相太近就换同色系的邻近色。列表里的小品牌 logo 不算冲突。
4. 强调色用在文字上时，对比度至少 4.5:1（浏览器开发者工具里能直接看）；做一个更深的文字色和一个很浅的底色配合使用。
5. 金融涨跌按中国习惯**红涨绿跌**；红色在国内也是喜庆色，所以错误状态要配文字或图标，不能只靠红色。

在交付报告里用一句话说明选了什么颜色、为什么。

## 4. 中文排版与国内环境

- **字体**：随项目打包一套中文界面字体，让中文和数字是同一套：`npm install misans`（按 `unicode-range` 分片，只下载用到的字）或 HarmonyOS Sans。字体栈：`"MiSans", -apple-system, "PingFang SC", "Microsoft YaHei", sans-serif`。只靠系统字体时，Windows 上是雅黑配另一套数字，看起来别扭。
- **字号**：正文 15–16px，行高 1.6–1.75；辅助 12–13px；手机输入框至少 16px（防止 iOS 放大）。
- **字重**：400 / 500 / 600 三档。大数字用 600 就够，不用 800 粗体；中文不用负字距。
- **不用斜体**：中文斜体是机器拉斜的。强调用字重、颜色或底色。
- **数字**：金额和日期用 `font-variant-numeric: tabular-nums` 对齐；写法 `¥1,234.00`、`10月24日 周六`、`3 分钟前`。
- **文案**：口语、短句；按钮写动作（“添加订阅”）；中英文之间加空格。
- **大陆能打开**：不用 Google Fonts、reCAPTCHA、Firebase、Google 地图；依赖用 npm 装进项目，安装慢就用 `registry.npmmirror.com`。地图用高德或腾讯，短信和验证码用阿里云或腾讯云。
- **手机优先**：先按 375–430px 设计，主按钮放在拇指够得到的底部；很多链接会在微信内置浏览器里打开，它不能直接下载文件。

## 5. 布局

先写一句“用户打开页面最常做的事”，再找做同一件事的参考产品借骨架：

| 核心动作 | 参考 | 骨架 |
| --- | --- | --- |
| 管理一批条目（任务、订阅、账单） | 滴答清单 | 分类侧栏 + 分组列表 + 详情栏 |
| 随手记录、回顾 | flomo | 侧栏（统计 + 热力图 + 标签）+ 居中卡片流，输入框在最上面 |
| 写文档 | 思源笔记 | 文档树 + 编辑区（正文 ≤ 720px）+ 大纲 |
| 和 AI 对话 | LobeChat、Cherry Studio | 会话列表 + 对话；回答按文章排版不加气泡；输入框固定底部 |
| 读信息流 | Folo | 来源 / 条目 / 阅读三栏 |
| 个人主页、博客 | Innei | 单栏居中 + 底部浮动导航 |
| 管理多个项目 | Dify | 顶栏 + 卡片网格，进项目后换侧栏 |
| 介绍产品 | Cherry Studio、Bob | 大标题点亮一两个词 + 黑色主按钮 + 真实产品截图 |

这些是参考，不是必须从中挑一种。手机上：侧栏变抽屉或顶部标签，详情变新页面或底部面板。

**防空洞**：

- 并排两栏高度差超过一半，就改一栏，或把短的一栏固定（sticky）。
- 数据稀疏（有数据的日子不到三分之一）不画柱状图，改成“接下来几笔”的列表或时间线。
- 卡片里只有一两行字就不要用大卡片。
- 阅读和列表区最宽 640–760px，多出来的宽度给侧栏或详情。

## 6. 组件：做与不做

照着 [组件配方](../assets/patterns.html) 写，那一页并排放了“照做”和“不要这样”。

| 做 | 不做 |
| --- | --- |
| 列表扁平分组：一行 = 图标 + 标题 + 一行灰色说明 + 右边一个数字或时间，行高约 44px | 每行一张带边框阴影的卡片，再塞徽章、进度条、两个按钮 |
| 每个实体一个图标：品牌用 `simple-icons` 或 `@lobehub/icons` 的真实 logo，放在 14% 品牌色浅底方块里；用户自建的内容用 emoji | 整页只有文字 |
| 编辑、删除放进悬停菜单、右键或详情页 | 每行摆一排按钮 |
| 首屏大数字 600 字重，旁边一句人话说明 | 800 粗体大数字，下面一串挤在一起的灰字 |
| 图表只用强调色的深浅，“今天”或最高值用实色 | 深灰色的细柱，像默认图表库 |
| 提示条用中性浅灰底，强调色只给里面的链接 | 大块粉橙色底，比正文还抢眼 |
| 删除后给“撤销” | 每次都弹确认框 |
| 输入框有可见的标签，错误就近提示，失败不丢输入 | 只靠 placeholder；出错清空表单 |
| 状态用颜色加文字或图标表示 | 只靠颜色区分 |
| 操作用 `button`、跳转用 `a`，键盘能走完主路径，焦点看得见 | 用 `div` 做按钮 |

## 7. 动效

- 大多数动画不超过 300ms；高频操作（键盘、菜单）不加动画。
- 只动 `transform` 和 `opacity`，不写 `transition: all`。
- 列表增删用 FLIP 平滑让位；新内容从触发它的位置出现。
- 按下按钮缩到 0.97；面板和提示可以有轻微回弹。
- 每个产品有一个和核心动作相关的“招牌交互”就够，例如记一条想法后它落进列表、AI 流式输出带光标并能随时停止。
- `prefers-reduced-motion` 下关掉动画，结果照常显示。

## 8. 交付前自查

在桌面（1280px）和手机（375px）各截一张图，看：

- 中文和数字是同一套字体吗？
- 除了强调色还有别的彩色吗？主题是不是还是组件库默认的样子？
- 列表是不是一行一张卡片？实体有没有图标？
- 有没有超过四分之一屏的空白？
- 手机上按钮有没有压住文字、有没有横向滚动？
