# 离线工作流决策：A–E

仅依据指定 skill、四份参考和场景事实作决策。未联网、安装、修改产品或执行验证。下列动作均为拟执行；已有通过项仅引用题设。

## A：投入、截止与局部认可

接下来三项动作：
1. 保留现有后端和页面，记录自动采集仍是核心目标、轻点背面仅为备选；分开列出保存/读回及构建通过与手机触发、识别未验证。
2. 优先围绕甲乙原生快捷指令设计最小验证：目标 iOS 上取得真实消费输入、识别并生成同步账单；甲识别费用、乙模型依赖和安装版本均待核对。无真机且限浏览器，核心验证记为 `blocked`，不据此淘汰候选。
3. 半小时展示仅检查现有浏览器保存、读回与电脑查看，明确手工路径和无采集入口的边界；展示核心阻塞与后续真机验证步骤。

代码决策：不开始采集底座或依赖采集假设的 UI 扩建。截止、投入和“页面可以，继续”不能证明核心能力成立，也不改变自动目标。

当前交付：阶段性页面展示说明、复用未知项表与真机验收清单。整体需求未满足；浏览器检查不能证明手机触发和识别，本轮也未复验题设通过项。

## B：从需求找方案

接下来三项动作：
1. 固定比较路径：三门店扫码预约、店员按门店权限看排班；不把模板功能反推为需求。
2. 条件推荐甲优先、乙备选：甲覆盖目标路径，但免费层不满足三门店，价格与试用限制未知；乙部署与商用许可未知。丙仅登录、表格，不是预约业务底座。
3. 准备试用脚本：三门店配置→扫码预约→对应排班可见→跨店访问边界；列出甲试用入口、三店套餐、数据导出及乙部署/许可的待核对项。离线时不能执行入口核实与真实试用，不购买或部署。

代码决策：不建模板工程或自写预约排班。用户优先直接使用服务，完整候选尚未证实不适配。

当前交付：基于题设的条件推荐、候选对照和试用脚本。不能提供虚构代号的真实试用链接或确认价格；“能试用的方案”仍待入口与套餐核实，本轮无法完整交付该结果。

## C：已有应用的局部修复

接下来三项动作：
1. 定位 Vue 筛选、请求参数、FastAPI 查询及已有测试，核对 Asia/Shanghai 日期与 UTC 存储转换、起止包含语义；不预断根因。
2. 用固定时间和现有测试复现漏单，覆盖上海昨天零点附近、昨天末尾及今天零点，断言昨日应出现、区间外应排除；核对本地自然日边界转换后的 UTC 范围。
3. 根因确认后做最小修复，复用既有接口与工具，重跑失败用例、相邻日期回归及适用的页面检查；不装包，记录实际结果。

代码决策：流程上可在复现确认后开始局部修复；本轮仅决策，未改代码。已定平台的小缺陷无需市场搜索或迁移，广告不构成换平台依据。

当前交付：定位、复现和修复计划；根因待确认，复现与回归均为 `not-run`，不能声称已修好。

## D：核心受阻，独立视觉任务仍可推进

接下来三项动作：
1. 查现有组件、样式及实际字体，保存同尺寸基线；固定绿色、中文、业务行为与后端，不重复询问品牌。
2. 在现有设施内做可撤销、限定作用域的字体/间距比较片段；原样与调整版消费相同账单、长中文及金额日期，不装库、不扩成整套产品。
3. 同尺寸比较排版，并检查受影响的窄屏、中间宽度、关键操作和焦点；交付差异与回退方式，用户选择后再扩展。采集权限另记受阻。

代码决策：可开始已授权的局部样式修改；本轮只决策，未实际修改。片段独立于手机权限，不需重开选型或新增审批。

当前交付：比较范围与回退/验证计划；执行后可交付片段、截图和差异。本轮没有实际片段，检查为 `not-run`，新排版的用户判断为 `pending`；不宣称核心产品可行。

## E：宣传与源码不一致

接下来三项动作：
1. 记录证据差异：README 宣称免费、离线 OCR；指定 revision 未配模型会跳过截图入口；安装版本未知。记账、同步、CSV 局部通过不等于采集通过。
2. 沿指定 revision 核对跳过条件、模型调用与其他可能的离线 OCR 入口，对齐文档版本和手机实际版本；未知保持未知，不凭单一入口否定全部版本，不调用外部模型。
3. 定义真机最小验收：真实消费输入/截图→触发→识别→正确账单→电脑读回，自动与手动路径分开。无真机且版本未知，核心验证为 `blocked`，保留已有工作并暂停依赖该能力的首页改造。

代码决策：不能宣布满足自动采集，不开始首页改造。当前授权是继续验证，宣传与局部通过不足以跨过核心关口。

当前交付：版本差异表、候选状态和无未经授权外部模型调用的验收计划。自动采集未满足且验证受阻；不等于候选已被证实完全不可用。本轮源码补查、真机验证均未执行。
