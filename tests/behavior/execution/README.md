# 实际执行夹具

将每个子目录复制到隔离目录，再向无父对话的执行者提供 TASK.md、指定条件下的 skill 和副本路径。执行者实际编辑或运行，不给本文件的评审口径，也不开放其他条件的结果。保存原始输出和最终产物，评审者重新运行 checks.py 或 probe。

条件可包括无 skill、冻结旧版、修订版；每个条件应使用相同初始文件、请求和工具权限。一次通过不是成功率测量。夹具均为 Python 标准库，不接真实账户、手机或外部服务。

评审实际产物：

- calendar：本地日期的起止、带偏移时间、月边界与输入顺序；保留失败到通过的证据，未引入其他栈或产品。
- archive：真实 SQLite 状态与版本、角色与租户范围、审计/outbox、重复写与事务回滚；拒绝操作无副作用。不将领域函数测试称为 HTTP/UI 或完整 SaaS 验收。
- capture：确实运行入口并记录退出码；区分手工保存和采集受阻，保留原目标和备选。不扩建依赖未知能力的产品，也不假称完成真机验证。

这些夹具补充原有离线决策场景；没有覆盖真实 UI、长会话稳定性、设备触发、并行实例或生产容量。
